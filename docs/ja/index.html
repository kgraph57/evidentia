なぜ今か

捏造文献は、もう珍しくない

生物医学論文を対象にした Lancet の監査（Topaz et al., 2026）では、捏造文献は 2023年は2,828本に1本、2025年は458本に1本（約6倍）、2026年最初の7週間は277本に1本。2023年比で約10倍で、生成AIライティングの普及と時期が重なる。捏造DOIは本物と見分けがつかない。Evidentia は識別子を一つずつ解決して、どれが本物かを示す。

Topaz et al., Lancet 2026;407(10541):1779–1781. doi:10.1016/S0140-6736(26)00603-3 · STAT、2026年5月7日 · PMCオープンアクセス収載分
4段階分類

「検証できませんでした」で終わらない。理由を出す。

多くの引用チェッカーはそこで止まる。Evidentia は識別子を解決し、なぜ怪しいのかを示す。

[OK] 検証済み

論文は実在し、引用のタイトル・著者・年・誌名がレジストリ記録と一致する。

[REV] 内容レビューが必要

レジストリでは確定できない（書籍・ガイドライン・タイトルのみ）、または実在論文でも、正しい文脈で使われているかの確認が人間かLLMに残る。

[MIS] 書誌の不一致

実在する論文だが、DOI/PMID が誤っているかメタデータが食い違う。雑な引用か、本物のタイトルに捏造識別子を付けたもの。

[HAL] ハルシネーション

識別子が何も解決しない、またはまったく別の論文を指す。AI生成テキストの典型。

2層構成

推測しないエンジンと、判断するスキル

分けているのは意図的。存在の確認は決定論。使い方の誠実さには判断が要る。

エンジン · CLI + MCP

この論文は実在するか

純粋なレジストリ照合。DOI / PMID / arXiv / NCT を CrossRef、PubMed、OpenAlex、arXiv、ClinicalTrials.gov へ。APIキー不要、LLMなし、エンジン自身はハルシネーションしない。

npx evidentia check · claude mcp add evidentia -- npx -y evidentia-mcp

スキル · 15項目

正しく使われているか

エンジンを15項目の評価ルーブリックで包む。エビデンスレベル、統計、因果と相関、利益相反、誇張、対象集団、倫理 — A–F のレポートと具体的な直し方。エンジンだけではできない Tier 2 の層。
